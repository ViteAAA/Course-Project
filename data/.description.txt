- data.csv          -   содержит данные для верефикации программы
- data.xlsx         -   содержит расчеты data.xlsx


- dataPos1.csv      -   содержит записи, в которых в столбце экспорта 0
- dataPos1.xlsx     -   содержит расчеты dataPos1.csv

- dataPos2.csv      -   содержит меньшее колличество записей, чем в data.csv
- dataPos2.csv      -   содержит расчеты dataPos2.csv


- dataBord1.csv     -   не содержит записей (только заголовок)
- dataBord1.xlsx    -   содержит расчеты dataBord1.csv

- dataBord2.csv     -   содержит только 1 запись
- dataBord2.xlsx    -   содержит расчеты dataBord2.csv

- dataBord3.csv     -   содержит записи с одинаковыми фирмами, но разной продукцией
- dataBord3.xlsx    -   содержит расчеты dataBord3.csv

- dataBord4.csv     -   содержит записи с одинакой продукцией, но разными фирмами
- dataBord4.xlsx    -   содержит расчеты dataBord4.csv


- dataCritical1.csv -   содержит записи, в которых на экспорт ушло больше, чем было произведено

- dataCritical2.csv -   содержит записи с отрицательными значениями экспорта и/или произведенных товаров

- dataCritical3.csv -   содержит записи, в которых нет ничего, кроме произведенных товаров и отправленных на экспорт

- dataCritical4.csv -   содержит записи, в которых товары не производились и не отправлялись на экспорт
